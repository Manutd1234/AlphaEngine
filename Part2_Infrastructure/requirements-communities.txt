# Optional: community detection and centrality over the research graph.
#
#   pip install -r requirements-communities.txt
#
# Separate from requirements-graph.txt because the two are independent: the
# graph projection needs a Neo4j driver and a reachable instance, while Louvain
# and PageRank run in process over the edge list and need neither. A desk that
# wants community summaries without operating a graph database installs only
# this one.
#
# networkx is pure Python — no compiler, no wheel roulette, no GPU. That is why
# the algorithms run here rather than in Neo4j's GDS library, which the Aura
# Free tier does not carry.
networkx>=3.2
# networkx's PageRank has been scipy-backed since 3.x — nx.pagerank imports
# scipy or raises. Louvain alone runs pure-Python, which is how this file
# shipped without scipy and stayed green on every machine that had it via
# requirements-ml.txt, then failed only in CI. Declared here so the extras
# file states what the module actually needs, not what one laptop had.
scipy>=1.11
