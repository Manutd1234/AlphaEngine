# Optional extra for tools/graph_recall.py — the research-graph recall CLI.
#
#   pip install -r requirements-recall.txt
#
# It pins ONE package, and that package is already in requirements-core.txt.
# The file exists so the tool can be run from a minimal environment (a laptop
# with nothing but a venv and a Supabase key), not because the tool adds
# anything to the gateway's dependency set.
#
# NOT HERE, DELIBERATELY: the Anthropic SDK.
#
# `--narrate` reaches Claude by shelling out to the `claude` CLI over stdin.
# That keeps the integration outside the Python dependency graph entirely: no
# SDK in requirements-core.txt, no npm package in web/, no API key read by this
# process and none passed on a command line — argv lands in the process table
# and the shell history, and `claude` manages its own auth.
#
# The fallback is built in rather than documented: if `claude` is not on PATH,
# or exits non-zero, or prints nothing, the CLI says so with the reason and
# prints the deterministic traversal anyway. `--narrate` is never required for
# an answer, and `--json` never involves it at all. Unconfigured must never
# look like empty, and an absent narrator must never look like a silent skip.
#
# Nothing under modules/ or main.py may import the tool: it is invoked by a
# person, and a non-deterministic, unbounded-latency call has no place in a
# request path. tests/test_graph_recall.py holds both lines.
