# Optional supervised-learning extra.
#
# Deliberately NOT part of requirements-core.txt. The desk's ridge and logistic
# regression are hand-rolled in modules/ml/models.py and always available; this
# adds the model families that do not solve in closed form.
#
#   pip install -r requirements-ml.txt
#
# When it is absent, modules/ml/engine.py reports the ML strategies as
# UNAVAILABLE with the import error attached, and ml_runs.engine records
# 'numpy' for every run that took the hand-rolled path. A run that fell back is
# a different run and must not be ranked as though it were not — which is why
# the column exists and why this file does not quietly become a core
# dependency.
#
# scikit-learn is pinned to a major line rather than floated: a solver that
# changes between releases changes yesterday's coefficients, and the
# coefficients are the research result.
#
# Not 1.8.0. That release deprecated `penalty=` in favour of `C` alone, and
# its own `penalty=None` check reads `C != 1.0` — so `C=np.inf`, the spelling
# it recommends, trips the UserWarning it recommends against. The fit is
# bit-identical either way (measured against 1.9.0); the exclusion exists so
# the adapter's unpenalised path is warning-free on every version this file
# admits, rather than papering over one release with a warnings filter.
scikit-learn>=1.5,!=1.8.0,<2.0
